## 2. Existing API Client (`apiClient.ts`)
The centralized HTTP client is defined in [`frontend/services/apiClient.ts`](file:///Users/hardik/Downloads/IBVAP/frontend/services/apiClient.ts):
- **Base URL Resolution:** Reads `NEXT_PUBLIC_API_URL` (defaulting to `http://localhost:8000`) and normalizes it to append `/api/v1`.
- **JWT Authorization:** Inspects `localStorage.getItem("ibvap_access_token")` / `localStorage.getItem("ibvap_token")` and injects `Authorization: Bearer <token>` into HTTP headers unless `skipAuth: true`.
- **Error Handling:** Standardized `ApiError` class capturing HTTP status codes (401, 403, 404, 409, 422, 500) and structured backend error details (`error.message` / `detail`).
- **Global 401 Interception:** Clears stored access tokens and redirects browser to `/login` when unauthenticated requests fail (skipping login/MFA challenge endpoints).

## 5. Existing WebSocket Implementation
Defined in [`frontend/hooks/useWebSocket.ts`](file:///Users/hardik/Downloads/IBVAP/frontend/hooks/useWebSocket.ts):
- **Endpoint URL:** `ws://localhost:8000/api/v1/ws/events?token=<JWT>` (falls back to `ws://localhost:8000/api/v1/ws/alerts?token=<JWT>`).
- **Authentication:** Obtains JWT token from `authService.getStoredToken()` and passes as query parameter.
- **Reconnection Policy:** Bounded exponential backoff with max 5 reconnect attempts and status tracking (`CONNECTING`, `OPEN`, `CLOSING`, `CLOSED`).
- **Heartbeat:** Periodically sends `{"type": "ping"}` frame every 30 seconds to keep connection active.
- **Event Handler:** Listens for `EVENT_CREATED`, `ALERT_GENERATED`, or `INTRUSION_DETECTED` frames and notifies [`frontend/context/AlertContext.tsx`](file:///Users/hardik/Downloads/IBVAP/frontend/context/AlertContext.tsx).

## 6. Authentication State Implementation
Managed via [`frontend/context/AuthContext.tsx`](file:///Users/hardik/Downloads/IBVAP/frontend/context/AuthContext.tsx) and [`frontend/services/authService.ts`](file:///Users/hardik/Downloads/IBVAP/frontend/services/authService.ts):
- **Token Storage:** Uses `localStorage.setItem("ibvap_access_token", token)` and `localStorage.setItem("ibvap_token", token)`.
- **RBAC Helper:** Injects `hasRole(allowedRoles: string[])` into `useAuth()` to conditionally render UI controls (e.g. Audit Logs link visible to `ADMINISTRATOR` and `AUDITOR`).
- **Session Check:** On initial app mount, invokes `authService.getCurrentUser()`. If valid token exists, sets `user` state; if missing or 401, sets `UNAUTHENTICATED`.
