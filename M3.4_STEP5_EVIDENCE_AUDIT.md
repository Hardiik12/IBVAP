## 1. Evidence REST API Contracts

| Endpoint | Method | Role Permission | Request Schema | Response Schema | Description |
|---|---|---|---|---|---|
| `/api/v1/evidence` | `GET` | All authenticated roles | Query: `limit=50` | `List[EvidenceResponse]` | Lists all digital evidence records sorted by `captured_at` desc |
| `/api/v1/evidence/{id}` | `GET` | All authenticated roles | Path: `id` | `EvidenceResponse` | Fetches single evidence record metadata & stored hash |
| `/api/v1/evidence/{id}/image` | `GET` | All authenticated roles | Path: `id` | `FileResponse (image/jpeg)` | Streams raw binary JPEG frame from disk |
| `/api/v1/evidence/{id}/hash` | `POST` | Operator, Administrator | Path: `id` | `EvidenceHashResponse` | Calculates & persists authoritative SHA-256 binary hash |
| `/api/v1/evidence/{id}/verify`| `GET` / `POST` | All authenticated roles | Path: `id`, Query: `simulate_tamper=bool` | `EvidenceVerificationResponse` | Recalculates file hash on disk and compares against PostgreSQL stored hash |
| `/api/v1/evidence/capture` | `POST` | Operator, Administrator | `EvidenceCaptureRequest` (base64) | `EvidenceDetailResponse` | Real-time intrusion webcam frame ingestion, hashing, and event/alert linkage |

## 3. Cryptographic Lifecycle & Path Security
- **Strict Server Authoritative Hash:** Hash is computed exclusively in backend `EvidenceIntegrityService` using Python `hashlib.sha256(file_bytes).hexdigest().lower()`.
- **Path Traversal Protection:** `EvidenceIntegrityService.resolve_path_safely` canonicalizes paths relative to `settings.EVIDENCE_ROOT` and rejects arbitrary path traversal attempts (e.g. `../../etc/passwd`).
- **Audit Trail Integration:** Every verification execution dispatches `AuditService.log_action(..., action="EVIDENCE_VERIFIED")` recording actor, verification status, and timestamp.
