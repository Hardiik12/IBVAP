## 2. Detailed Audit Analysis

### 2. JWT Processing & Token Storage
- **File:** [`frontend/services/authService.ts`](file:///Users/hardik/Downloads/IBVAP/frontend/services/authService.ts)
- Authoritative session tokens are stored in `localStorage` under `ibvap_access_token`.
- Temporary Step 1 MFA challenge tokens are stored in `sessionStorage` under `ibvap_mfa_pending`.

### 3. Route Protection & Redirects
- **File:** [`frontend/components/layout/AppShell.tsx`](file:///Users/hardik/Downloads/IBVAP/frontend/components/layout/AppShell.tsx)
- Routes are categorized into `AUTH_ROUTES` (`/login`, `/mfa`, `/mfa/setup`) and Protected Routes.
- If `authState === "UNAUTHENTICATED"` on protected routes, `router.replace("/login")` triggers immediately.

### 4. WebSocket Security
- **File:** [`frontend/hooks/useWebSocket.ts`](file:///Users/hardik/Downloads/IBVAP/frontend/hooks/useWebSocket.ts)
- Connects to `ws://localhost:8000/api/v1/ws/events?token=<JWT>`.
- Backend closes connection with status `1008 Policy Violation` if token is missing or invalid.
