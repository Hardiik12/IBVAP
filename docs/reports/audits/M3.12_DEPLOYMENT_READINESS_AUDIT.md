## I. Security Audit

1. **Password Hashing:** 100% of passwords use memory-hard **Argon2id** (`pwdlib[argon2]`). Zero plaintext passwords in database.
2. **Path Traversal Hardening:** [`EvidenceIntegrityService`](file:///Users/hardik/Downloads/IBVAP/backend/app/services/evidence_integrity_service.py) rejects null-bytes (`\0`), leading slashes, and traversal sequences (`../`), resolving paths strictly within `EVIDENCE_ROOT`.
3. **CORS Security:** Rejects wildcard `*` when credentials are enabled.
4. **Brute-Force Rate Limiting:** Sliding-window rate limiter blocks login after 5 consecutive failed attempts (HTTP 429).
5. **Production Secret Requirements:** In production deployments, `JWT_SECRET_KEY` and database passwords must be randomized via `openssl rand -hex 32`.

## O. Recommended Production Architecture (Nginx Reverse Proxy)

For live border security field outposts, deploy behind Nginx for single-port TLS termination:

```nginx
# /etc/nginx/sites-available/ibvap.conf
server {
    listen 443 ssl http2;
    server_name surveillance.border.internal;

    ssl_certificate /etc/ssl/certs/ibvap.crt;
    ssl_certificate_key /etc/ssl/private/ibvap.key;

    # Frontend Tactical Command Center
    location / {
        proxy_pass http://127.0.0.1:3000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }

    # Backend REST API
    location /api/ {
        proxy_pass http://127.0.0.1:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }

    # Real-Time WebSocket Alerts
    location /api/v1/ws/ {
        proxy_pass http://127.0.0.1:8000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_set_header Host $host;
        proxy_read_timeout 86400s;
    }
}
```
