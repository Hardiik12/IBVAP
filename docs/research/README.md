# Research Documentation Index

This directory holds research studies supporting the IBVAP Internal-Round evaluation.

- `problem-study.md`: Manual CCTV surveillance limitations & perimeter monitoring workload.
- `existing-solutions.md`: Analysis of commercial VMS/CCTV analytics vs IBVAP design.
- `yolo-research.md`: Evaluation of object detection models for real-time edge processing.
- `tracking-research.md`: Multi-object tracking (ByteTrack) identity persistence & state transition logic.
- `evidence-integrity.md`: Digital evidence chain-of-custody, SHA-256 cryptographic verification, and auditability.
- `edge-vs-cloud.md`: Latency, bandwidth, privacy, and resilience tradeoffs in border surveillance.
