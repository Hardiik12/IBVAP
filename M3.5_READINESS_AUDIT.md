## 2. Failure Mode & Resilience Assessment

1. **PostgreSQL Unavailable:** Backend reports degraded status (`database: disconnected`); frontend displays `BACKEND ● OFFLINE | DB: DISCONNECTED`.
2. **Backend Stopped:** Frontend transitions smoothly to `BACKEND ● OFFLINE | WS: OFFLINE`; reconnects automatically upon backend restart.
3. **AI Pipeline Stopped:** Video stream terminates cleanly; existing events and alerts remain accessible in historical views.
4. **WebSocket Disconnected:** `useWebSocket` initiates bounded exponential backoff (up to 10s delay); resumes live alerts upon reconnection.
5. **Evidence File Tampered:** Recalculated disk binary hash differs from PostgreSQL digest; `HashVerifier` displays 🔴 `MISMATCH (TAMPER DETECTED)`.
6. **Model Checksum Invalid:** `AI_MODEL_SHA256` mismatch raises `RuntimeError` during model load and prevents unauthorized model execution (Fail Closed).
7. **Duplicate Event Submission:** Idempotent event identifier returns HTTP 409 Conflict, preventing duplicate database alerts or audio triggers.
